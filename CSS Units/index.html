CSS Units(px, em, rem, %, vw, vh)

This is a child element.

rem(root em) main use hota hain.
rem hamesha root element (html) ke font size par depend karta hain.
Agar root element ki font size 16px hain to rem value 1rem hoga to element ki font size 16px hoga.
Agar root element ki font size 16px hain to rem value 2rem hoga to element ki font size 32px hoga.

Modern best practices

* Font size ke liye rem use karo.
* Layout ke liye % use karo.
* Spacing ke liye px use karo.
* Responsive design ke liye vw aur vh use karo.
* Avoid using em for font size, use rem instead for better consistency.
